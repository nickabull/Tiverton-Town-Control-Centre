Editorial Inbox · User Guide
  1. Receive a Word report or preview from Darren by email; download it once for the browser importer. Fully automated Gmail delivery requires secure setup.
  2. Import the .docx. It is parsed locally in the browser. The original is retained and never overwritten by suggested edits.
  3. Review red errors first, then amber fact/name checks. Use Apply correction, Ignore or manually edit the copy.
  4. Re-scan after changes. The corrections log records what has been accepted.
  5. Approve a snapshot only after checking the text. This makes it available to Programme Studio (in the same browser) and unlocks copy/export for Wix.
  6. Download the inbox JSON backup before clearing this browser or moving computers. Nothing in this tool automatically publishes to Wix.
Changes to the working text after approval require another approval to update the published-ready snapshot. Fictional or disputed football facts must not be silently rewritten.
