Make the canvas your workspace. Use the LAYERS and INSPECTOR buttons above the page to show or hide the side panels.

ARRANGE ARTWORK

Select any unlocked layer, then drag to move it. Use blue handles to resize, or set exact values in the inspector. Shift-click to select more than one layer.

EDIT TYPE

Double-click the text or select it and press EDIT. Highlight words before using bold, underline, alignment or font sizes.

KEYBOARD & STORAGE

Ctrl+C copies selected layers; Ctrl+V duplicates them. Use Undo for recent changes. The save indicator must confirm SAVED IN THIS BROWSER. Download a JSON backup regularly; cloud saving is not connected.

ORIGINAL REFERENCE

ORIGINAL TRACE is a visual reference only and is not exported as page artwork. Lock your background and brush strokes when your master looks right.

More detailed editor notes

Ctrl+C copies selected layers; Ctrl+V pastes duplicates. Click grey space outside the page to clear selection. Shift+click layers in the canvas or layer list to select several, then drag them together. Drag the blue bottom handle for height, right handle for width, or corner for both. The exact WIDTH and HEIGHT values also remain available in the inspector. Double-click a text layer to edit directly on the page, or select it and press EDIT in the toolbar above. Formatting affects selected wording or the selected paragraph. This is a proof of the editor and layer model, not yet an exact typeset reproduction. Your actual original artwork is used. Text is editable, images retain individual transparency, and no changes go to V1 or Canva.
