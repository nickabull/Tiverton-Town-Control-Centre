1. Load the programme

Select the final PDF. The file is read in your browser; it is not uploaded to a server by this tool. Scanned pages and artwork embedded as images may not be text-searchable.

2. Review findings

All findings are prompts for editorial review, not confirmed errors. This tool never changes your PDF or Canva design.

What this first version checks

Text extraction by PDF page; duplicate words; frequent spelling mistakes; inconsistent spellings of Barnstaple; advertised dates older than the selected match date (where detected); opponent and match-date mentions; potentially missing official player names; blank/textless pages; and page numbering. Names, scores, fixtures, source statistics, photographs and Canva overflow still require a visual/manual check.
