Connect News Publisher to Wix

The dashboard is prepared. These two small backend files must be installed in the existing Tiverton Town Wix site before the Publish button can send an article.

No Wix API key or password needs to be pasted into the dashboard. The backend checks your existing Programme Centre sign-in before allowing a write.

  1. Open the existing Tiverton Town FC site in Wix Editor and enable Dev Mode.
  2. Under Backend & Public → Backend, add a regular JavaScript file named news-publisher.js. Copy the first block below into it.
  3. Open http-functions.js under Backend, or create it using Expose site API. Add the second block, preserving any existing functions.
  4. Save and Publish the Wix site to activate the backend. This does not publish your news draft.
  5. Return to News Publisher and click Check connection. The status must say Connected to Tiverton Town News before trying the article.
